LEKKISUITES - DEPLOY ON RENDER (FREE)
=====================================
This folder is ready to publish. It already contains:
  app.py           - the website
  templates/       - all the pages
  static/          - pictures, styles, logos
  requirements.txt - the Python packages Render must install
  Procfile         - tells Render how to start the site
  runtime.txt      - Python version

HOW TO PUBLISH (do this once)
1. Go to github.com and create a free account (if you don't have one).
2. Click "New repository". Name it: lekkisuites. Keep it Public. Create.
3. On the new repo page click "uploading an existing file".
4. Drag EVERY file and folder from this folder into the browser.
   (Select all inside this folder - do NOT upload the folder itself.)
5. Click "Commit changes".
6. Go to render.com, sign up with your GitHub account.
7. Click "New +"  ->  "Web Service"  ->  connect the lekkisuites repo.
8. Fill in:
      Language:      Python 3
      Build Command: pip install -r requirements.txt
      Start Command: gunicorn app:app
      Instance Type: Free
9. Click "Create Web Service". Wait 2-3 minutes for it to build.
10. Render gives you a link like https://lekkisuites.onrender.com
    Open it - your website is LIVE.

CONNECT YOUR DOMAIN (lekkisuites.com)
1. In Render: your service -> Settings -> Custom Domains -> Add Custom Domain
2. Type: lekkisuites.com   (and also www.lekkisuites.com)
3. Render will show you 2 records (a CNAME and/or an A record / ALIAS).
4. Open Whogohost -> your domain -> DNS / Manage DNS.
5. Add the records Render showed you. Save.
6. Wait 10-60 minutes. Render will show "Certificate issued" - then your
   domain works: https://lekkisuites.com

IMPORTANT ABOUT FREE PLAN
The site sleeps after 15 minutes with no visitors. When someone opens it,
it wakes up in about 5-20 seconds. That is normal on the free plan.

IMPORTANT ABOUT BOOKINGS DATA
The free plan has no permanent disk. If Render restarts your app,
bookings saved in bookings.db can be lost. Fine for launching and showing
your uncle. When the hotel starts getting real bookings every day,
upgrade to a paid plan + add a Render Disk, or move to Postgres.
